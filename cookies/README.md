# Cookies locaux

Le dossier `cookies/incoming/` est réservé aux exports appartenant à
l’utilisateur ou utilisés avec une autorisation explicite. Un cookie de session
est aussi sensible qu’un mot de passe : ne le partagez pas et ne le commitez
jamais.

Les fichiers runtime de cookies doivent rester locaux. Ils ne sont pas ajoutés
aux rapports, au graphe d’enquête ni aux appels IA. Supprimez les exports après
usage et révoquez les sessions si un fichier a été exposé.

Le dossier est préparé dans l’architecture CAT.EXE. Les fonctionnalités de
navigation authentifiée dépendent d’un navigateur compatible et ne doivent
jamais automatiser une publication, une suppression ou une modification de
compte.
