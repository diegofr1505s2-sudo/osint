# Métadonnées et provenance

CAT.EXE lit localement les métadonnées d’image via Pillow. Les champs peuvent
inclure l’appareil, le modèle, le logiciel, l’auteur, les dates, l’objectif, la
focale, l’altitude, la direction, les dimensions et le GPS EXIF.

La présence d’un champ dépend du fichier original. Une absence de GPS ne
prouve pas qu’une photo n’a jamais été géolocalisée : les métadonnées peuvent
avoir été supprimées ou réécrites. Les coordonnées EXIF sont des données
techniques et ne prouvent pas à elles seules l’identité du photographe.

Les hypothèses produites par l’IA ou la géolocalisation visuelle restent
séparées des données EXIF déterministes. Les résultats doivent être vérifiés
avant toute conclusion.
