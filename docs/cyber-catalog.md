# Catalogue cyber

Le catalogue local se trouve dans `data/cyber_tools.json`. Il est dérivé du
dépôt public `diego1505-Art/hacking-ethique` et contient la source, la
catégorie, les plateformes, la licence, le risque et l’indication
d’installation de chaque ressource.

Le menu permet de rechercher et filtrer les ressources. Les outils à risque
élevé sont documentés pour l’apprentissage, la défense et les laboratoires
isolés. CAT.EXE n’exécute aucune commande d’installation ou d’outil depuis le
catalogue.

Utilisez uniquement vos propres systèmes ou une cible couverte par une
autorisation écrite. Les licences et l’état des dépôts doivent être vérifiés
sur la source officielle avant toute utilisation.
