# IA locale

CAT.EXE utilise Ollama en local lorsqu’il est installé. Les profils sont
séparés par tâche : texte, légère, vision, OCR, cyber et code. Les modèles,
leurs tailles et leur installation sont affichés avant tout téléchargement.

Aucune clé API n’est nécessaire pour Ollama et les prompts ne sont pas envoyés
à un service cloud par CAT.EXE. Une IA locale peut néanmoins conserver des
journaux selon sa propre configuration : vérifiez l’installation Ollama et
n’envoyez pas de données que vous n’êtes pas autorisé à traiter.

Les résultats IA sont indicatifs. Les données déterministes ont priorité :
EXIF réel, réponse API officielle, DNS réel et validations mathématiques ne
sont pas remplacés par une hypothèse de modèle.
